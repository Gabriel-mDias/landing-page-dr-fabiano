# Landing page — Dr. Fabiano Carvalho

Landing page editorial em Vite para o Dr. Fabiano Carvalho, ortopedista e traumatologista em Bom Jesus do Itabapoana (RJ). A conversão principal é o agendamento presencial pelo WhatsApp.

## Desenvolvimento

```bash
npm install
npm run dev
npm test
npm run validate:publication
npm run build
npm run preview
npm run smoke
```

O projeto permanece como demonstração com `noindex`. Domínio, canonical, sitemap definitivo, analytics, cookies, backend e deploy não estão habilitados.

Conteúdo e decisões aprovadas estão em `requisitos/briefing.md` e `requisitos/direcao-criativa.md`. Proveniência e licenças ficam em `docs/ativos-e-licencas.md`.
